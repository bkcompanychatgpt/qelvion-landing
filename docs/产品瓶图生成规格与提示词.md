## 二、每支瓶的贴纸文字（从上到下）

所有瓶统一，仅两行会变：

```
QELVION            ← 品牌（小字，含极简六边形标或纯文字均可）
BIOTECH            ← 可省略（空间小可不印）
────────────────
{product_label}    ← CSV 第 2 列，如 BPC-157 / GHK-Cu
{spec_label}       ← CSV 第 3 列，如 5 MG · LYOPHILIZED
FOR RESEARCH USE ONLY · ≥99% HPLC   ← 小字
条码 + LOT QV-88xx                   ← 底部装饰，可用任意假条码
```

> 品牌行、小字、条码是**每瓶完全相同**的固定部分；只有 product/spec 两行不同，靠 CSV 提供。

## 三、统一视觉规格（41 张必须一致，看起来才像同系列）

- 格式：**PNG，1:1 方形，1024×1024 起**
- 背景：**深藏青渐变 `#0A1424 → #0D1B2F`**（与网站暗色一致）；也可生成透明底，二选一但**全程统一**
- 构图：单支 10ml 硼硅玻璃西林瓶，**居中、占画面高约 85%**，银色铝盖 + flip-off 圆盖朝上，瓶内下部白色冻干饼清晰可见
- 光线：上方柔光 + 左右轮廓光，玻璃高光自然，瓶底轻微反射；无阴影地面、无桌面、无任何其它物体
- 禁用：水印、网页文字、角标、品牌以外的任何文案

## 六、如果文字总被画错（常见坑）

图像模型经常把 BPC-157、QELVION、≥99% 这类小字画错或糊掉。两条退路：
1. **要求重绘**：在提示词末尾加 `Spell every letter exactly as given; verify the label text is perfectly legible; if uncertain, render plain text without serifs.`
2. **空白标签方案（最稳）**：先只生成 1–2 张"无任何文字的空白白色标签瓶"（其余参数不变），把文字部分交给我用 SVG 精确叠印 —— 我可保证 41 个名称零拼写错误。需要走这条路的话告诉我，我把空白模板提示词发你。

## 八、logo 不要用图像模型画，统一程序化贴图（重要）

图像模型画不清晰的小 logo，因此**生成提示词里不要写 logo**；图片生成完后，用官方透明 logo 文件贴上去：
